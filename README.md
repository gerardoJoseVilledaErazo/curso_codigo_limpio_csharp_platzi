# curso_codigo_limpio_csharp_platzi
Aplicación de consola desarrollada en C# para gestionar tareas pendientes. Permite agregar, listar y eliminar tareas mediante un menú interactivo. Implementa colecciones (List&lt;T>), métodos, enumeraciones (enum) y estructuras de control, sirviendo como práctica de programación, lógica y fundamentos de desarrollo en .NET.
# ToDo Console App - C#

Aplicación de consola desarrollada en C# para la gestión básica de tareas pendientes.

## Características

* Agregar nuevas tareas.
* Listar tareas pendientes.
* Eliminar tareas existentes.
* Menú interactivo mediante consola.
* Uso de colecciones dinámicas (`List<string>`).
* Implementación de enumeraciones (`enum`) para mejorar la legibilidad del código.

## Tecnologías utilizadas

* C#
* .NET
* Visual Studio

## Conceptos aplicados

* Programación Orientada a Objetos.
* Métodos estáticos.
* Manejo de listas con `List<T>`.
* Enumeraciones (`enum`).
* Estructuras de control (`if`, `do-while`, `for`).
* Manejo básico de excepciones (`try-catch`).

## Objetivo

Este proyecto fue desarrollado con fines educativos para practicar la lógica de programación y la creación de aplicaciones de consola en C#.

## Posibles mejoras futuras

* Validación de entradas del usuario.
* Persistencia de datos en archivos o base de datos.
* Refactorización aplicando principios SOLID.
* Implementación de capas (Presentación, Negocio y Datos).
* Uso de pruebas unitarias.
